# SwipeCity — Pre-Submission Audit (2026-06-17)

Generated by a multi-agent audit (6 risk dimensions, every finding adversarially
verified): 29 raw findings → **21 confirmed**. Severities are the post-verification
adjusted values.

## Two lenses
- **Review-rejection risk** = could get the build rejected by Apple.
- **Product-works risk** = the app demos fine for a reviewer but the core
  swipe→interest→chat→transact loop is broken for real/returning users.

---

## Blocker (product)
1. **Posted listings never persist and never reach the buyer feed.** `List Item`
   only updates in-memory state; never calls `DataService.createItem`, never adds to
   the feed, never reloads on launch. Core marketplace loop has no real inventory path.
   `App.js:5356-5394`. Fix: persist via `DataService.createItem(...)`, merge into
   `seededItems`, reload user listings on mount. *(Likely passes review; breaks real use.)*

## High
2. **Returning users see stale data after ~1h** — `ensureValidToken` never refreshes a
   present-but-expired token, and `getUserProfile` sends the stale token then swallows
   the 401. `firebaseNative.js:381-397` (root) + `:479-496`.
3. **Saved items vanish on every relaunch** — `handleSaveForLater` is state-only; the
   persisting helpers are dead code. `App.js:1426-1471`, `321-322`.
4. **A buyer's "I'm interested" never reaches the seller** — interests live only in the
   buyer's React state. `App.js:1490-1516`, `1688-1725`.

## Medium
5. **Chat never syncs across devices** — sync gated on `window.firebaseServices`, which
   is never assigned. `App.js:2148`, `819`.
6. **Delete Account not reachable in seller mode** (5.1.1(v)) — only renders in buyer
   mode (the default), so reachable, but a reviewer in seller mode won't find it.
   `App.js:7121`, `7259-7340`. *(Review exposure.)*
7. **Duplicate Profile panel in seller mode** — two panels mount at once. `App.js:5855`
   + `6665`. *(Review exposure — quality.)*
8. **Onboarding category choice is discarded; feed personalization never works** —
   categories not saved, and numeric indices compared to emoji strings. `App.js:2908-2916`, `764`.
9. **Daily swipe/save limits reset on every launch** — counts never hydrated/persisted.
   `App.js:440-445`.
10. **Selecting a city can empty the feed** when seeded data is absent (fallback
    `mockItems` have no city). `App.js:731-744`, `24-79`.

## Low / post-launch
11. **Saved-items search can crash the app** if an item lacks title/description/price
    (unguarded `.toLowerCase()`). `App.js:7488-7495`. *(Conditional crash → review exposure.)*
12. **Dead `<input capture="user">` blocks** in both profile sections — orphaned but a
    latent re-arm hazard. `App.js:5922-6014`, `6733-6800`.
13. **"View Analytics" button does nothing.** `App.js:6337-6354`. *(Minor review exposure.)*
14. **`signOut` doesn't clear module-level `globalUser`.** `AuthContextNative.js:253-282`.
15. **Demo "Demo Seller" chat baked into the user's persisted chats.** `App.js:7808-7818`.
16. **`initializeDemoUser` unguarded `setItem` at module init.** `App.js:8216`.
17. **`NSPhotoLibraryAddUsageDescription` declared but unused** (both camera calls use
    `saveToGallery:false`). `Info.plist`. *(Minor review exposure.)*
18. **Privacy over-declares** — `SearchHistory` + policy text claim collection the app
    doesn't do. (Over-declaring isn't a rejection trigger.) `PrivacyInfo.xcprivacy`, `App.js:7980`.
19. **Auth `updateProfile` uses a stale token** — only called after signUp today (fresh
    token), so low impact. `firebaseNative.js:402-428`.

## Bottom line
One true product Blocker (#1) plus three High items break the loop for real/returning
users. The Medium/Low items with any **review** exposure are #6, #7, #11, #13, #17.
