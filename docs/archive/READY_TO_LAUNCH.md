## 🚀 Launch in 3 Steps (30 Minutes)

### Step 1: Firebase Setup (10 min)
```bash
# 1. Create Firebase project at console.firebase.google.com
# 2. Enable Authentication, Firestore, Storage  
# 3. Copy config values to .env file
# 4. Run automated setup
node scripts/setupFirebase.js
```

### Step 2: Seed Data (10 min)
```bash
# 1. Start your app
npm start

# 2. Press Ctrl+Shift+A to open admin dashboard
# 3. Click "Full Pre-Production (200 listings)"
# 4. Wait for seeding to complete
```

### Step 3: Deploy & Test (10 min)
```bash
# Deploy to Firebase hosting
firebase deploy

# Test on iOS
npx cap sync
npx cap open ios

# You now have a live app with real data!
```
